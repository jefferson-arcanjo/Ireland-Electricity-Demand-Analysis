# Ireland Electricity Demand Analysis

## Project Overview

This project explores electricity demand in Ireland and investigates how demand changes over time and relates to weather conditions.

The analysis will use data exploration and preparation techniques covered in the Data Exploration & Preparation module at CCT College Dublin.

## Objectives

- Explore electricity demand and weather datasets.
- Identify missing values, duplicates and potential outliers.
- Analyse electricity demand patterns using visualisations.
- Apply suitable data cleaning and transformation techniques.
- Investigate relationships between electricity demand and other variables.
- Explore feature selection and dimensionality reduction where appropriate.

## Tools

- R and RStudio
- Git and GitHub
- ggplot2 and dplyr
